PLAY IT. BREAK IT. REBUILD IT.

One small project, six real game-dev systems.

Every feature is intentionally separated into readable modules so a beginner can study one system without understanding the entire codebase.

01

Raycasting

DDA grid traversal turns a 2D map into a pseudo-3D world, one vertical screen column at a time.

02

Collision

Circle-based player collision keeps movement smooth while preventing walls and doors from being crossed.

03

Enemy AI

Enemies detect line of sight, chase the player, attack at close range and react to weapon hits.

04

Input

Keyboard, pointer and touch controls share one action layer, including animated thumbs that mirror the player.

05

Audio

Gunshots, pickups and damage sounds are synthesized through Web Audio, so no copyrighted sound files are needed.

06

Deployment

A GitHub Actions workflow type-checks, builds and publishes the project automatically to GitHub Pages.

REPOSITORY TOUR

Small enough to read. Structured enough to grow.

src/
├── game/
│   ├── audio.ts       # procedural sound
│   ├── constants.ts   # balancing values
│   ├── game.ts        # update loop + rules
│   ├── input.ts       # keyboard + touch
│   ├── level.ts       # map + entities
│   ├── renderer.ts    # raycaster + sprites
│   └── types.ts       # shared data models
├── ui/
│   └── hands.ts       # animated controls
├── main.ts            # bootstrap
└── style.css          # handheld + page UI

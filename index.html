A complete game-dev lesson hiding inside one pocket-sized project.

The presentation feels like a finished product, while every system remains small enough for a beginner to trace from input to pixels.

01

Raycasting

DDA traversal converts a readable 2D map into a pseudo-3D world one screen column at a time.

02

Combat

Hitscan targeting, ammunition, damage feedback, pickups and a complete win/death loop.

03

Enemy AI

Line-of-sight checks, chase movement, collision avoidance and close-range attacks.

04

Unified Input

Keyboard, pointer and multi-touch controls drive the same action layer and animated fingers.

05

Procedural Media

Sprites, wall patterns and sound effects are generated in code with no proprietary files.

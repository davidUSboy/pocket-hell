# Security policy

Pocket Hell is a static browser game and does not process accounts, payments or personal data.

## Reporting a vulnerability

Please do not open a public issue for a security problem. Use GitHub's private vulnerability reporting feature for this repository and include:

- the affected file or feature;
- clear reproduction steps;
- the browser and operating system;
- the expected impact;
- a suggested fix, when available.

Reports about gameplay bugs, layout problems or accessibility issues should use the public bug-report template instead.

# Changelog

All notable changes to Pocket Hell are documented here. The project follows semantic versioning.

## [2.0.0] - 2026-08-22

### Added

- Premium game-first handheld presentation with realistic materials, glass, controls, hands and responsive lighting.
- iPhone-first layout that places the playable console immediately inside the first viewport.
- Immersive focus mode, safe-area handling, Visual Viewport scaling and installable PWA metadata.
- Committed browser runtime so the game remains playable even when Pages is temporarily configured to serve the repository root.
- Local score history and a public GitHub Issues leaderboard with token-free score submission.
- Run score, timer, callsign, live status, mission panel and victory result flow.
- Offline application shell through a service worker.
- New desktop, mobile and social preview media.

### Changed

- Rebuilt the public page around the game instead of a conventional landing-page hero.
- Improved touch targets, multi-touch input, audio activation and mobile browser behavior.
- Strengthened validation and the GitHub Pages deployment pipeline.

## [1.0.0] - 2026-08-22

### Added

- Original TypeScript and Canvas 2D raycasting engine.
- Enemy AI, shooting, health, ammunition, pickups, doors and an exit condition.
- Procedural pixel sprites, wall patterns and Web Audio effects.
- Keyboard, pointer and touch controls.
- Documentation, CI, issue templates and MIT licensing.

# Changelog

All notable changes to Pocket Hell are documented here.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses semantic versioning.

## [1.0.0] - 2026-08-22

### Added

- Original TypeScript and Canvas 2D raycasting engine.
- Four enemies with line-of-sight detection, chasing and melee attacks.
- Shooting, ammunition, health, pickups, doors and an exit condition.
- Procedural pixel sprites and Web Audio sound effects.
- Keyboard, pointer and touch controls through one input layer.
- Interactive handheld shell with action-driven animated thumbs.
- Responsive portfolio page and GitHub Pages deployment workflow.
- Architecture, customization and beginner learning documentation.
- Repository validation, CI, issue templates and dependency updates.
- Guided Windows/macOS/Linux publishing scripts, release notes and CODEOWNERS.
- Open Graph metadata plus desktop, mobile and repository social previews.

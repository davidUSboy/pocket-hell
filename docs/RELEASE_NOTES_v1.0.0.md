# Pocket Hell v1.0.0

The first public release of Pocket Hell turns a beginner-focused raycasting engine into a complete, playable portfolio project.

## Included

- Canvas 2D raycasting renderer with depth-buffered procedural sprites
- player movement, strafing, collision and door interaction
- four enemies with line-of-sight chase and melee attacks
- shooting, ammunition, health pickups, damage, death and victory states
- keyboard, pointer and touch controls through one semantic input layer
- animated hands that react to the player's controls
- procedural Web Audio effects and generated pixel graphics
- responsive retro-handheld presentation
- English architecture, customization and learning documentation
- Russian quick-start guide
- automated validation, CI and GitHub Pages deployment

No proprietary DOOM, Nintendo or commercial game assets are included.

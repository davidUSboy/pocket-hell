# Pocket Hell: с чего начать

Pocket Hell — небольшой учебный шутер с псевдотрёхмерной графикой. Он написан на TypeScript и Canvas 2D без Unity, Unreal Engine и готового игрового движка.

## Быстрый запуск

```bash
npm install
npm run dev
```

После запуска откройте адрес, который покажет Vite.

## В каком порядке читать код

1. `src/game/level.ts` — карта и точки появления.
2. `src/game/constants.ts` — скорость, здоровье, боеприпасы и угол обзора.
3. `src/game/input.ts` — клавиатура, мышь и сенсорные кнопки.
4. `src/game/game.ts` — игровой цикл, столкновения, стрельба и искусственный интеллект.
5. `src/game/renderer.ts` — raycasting, стены, спрайты, оружие и интерфейс.
6. `src/game/audio.ts` — звуки, создаваемые через Web Audio.
7. `src/ui/hands.ts` — анимация пальцев на виртуальной консоли.

## Первое задание

Измените карту в `level.ts`, добавьте новую комнату и переместите одного противника. Затем выполните:

```bash
npm run validate
npm run typecheck
npm run build
```

Проект специально не содержит оригинальных файлов, графики или звуков DOOM и Nintendo. Для публичных работ используйте только собственные или совместимые по лицензии материалы.

## Публикация на GitHub Pages

Проект уже содержит workflow `.github/workflows/deploy.yml`. После отправки изменений в ветку `main` GitHub Actions проверит код, соберёт сайт и опубликует папку `dist`.

Для нового форка:

1. откройте **Settings → Pages**;
2. выберите **GitHub Actions** как источник публикации;
3. запустите workflow **Deploy Pocket Hell to GitHub Pages** или отправьте новый commit в `main`;
4. дождитесь зелёного статуса во вкладке **Actions**.

Адрес страницы будет выглядеть так: `https://USERNAME.github.io/pocket-hell/`.
